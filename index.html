O que é CSS?

CSS significa Cascading Style Sheets, ou, em português, Folhas de Estilo em Cascata.

É a linguagem responsável por definir a apresentação visual de um documento HTML.

Como trabalhar com o CSS?

Existem três formas clássicas de adicionar CSS em um documento HTML:

  • CSS inline
  • CSS interno
  • CSS externo

Conhecendo o CSS Inline

Nessa abordagem o CSS é colocado diretamente no elemento HTML atravé de um atributo chamado de style

Aplicando o atributo no elemento

Conhecendo o CSS Interno

Nessa abordagem, o CSS é colocado dentro de uma tag <style> no <head> do documento.

Conhecendo o CSS Externo

Nessa abordagem, o CSS é aplicado em uma folha de estilos externa, conectada por um elemento <link> dentro do <head> do documento.
